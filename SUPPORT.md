# Support

## Getting help

- **Usage questions:** start with the repository's README and any `docs/` folder.
- **Bugs:** open an issue using the **Bug report** form.
- **Feature ideas:** open an issue using the **Feature request** form.
- **Security vulnerabilities:** never use issues; follow the [security policy](SECURITY.md).

## Contact

For anything else, including collaboration and professional enquiries, use the contact details at [www.divyakush.com](https://www.divyakush.com).
