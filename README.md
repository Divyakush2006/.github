# Community health files

Default community health files for every repository owned by [@Divyakush2006](https://github.com/Divyakush2006).

GitHub applies these files to any repository that does not ship its own copy:

| File | Purpose |
| --- | --- |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Standards of behaviour for everyone taking part |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | How to report issues, propose changes and open pull requests |
| [`SECURITY.md`](SECURITY.md) | How to report a vulnerability privately |
| [`SUPPORT.md`](SUPPORT.md) | Where to ask questions and get help |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) | Structured bug report and feature request forms |
| [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | Checklist for every pull request |

A repository's own file, where present, takes precedence over these defaults.
